Mission 02 · Papers, Please0 / 150 XP

Set up your client

No papers, no port entry. Open your registry and choose Set up client — Harness hands you a ready-to-copy login command for your exact format. Auth runs on token-based credentials (PAT or service account), and tokens expire after 30 days.

Clear customs
$ <format> login <your-registry-url> -u <token>  # Login Succeeded
Mission 03 · Load the Cargo0 / 150 XP

Push your first artifact

With papers cleared, load the hold. Tag your build for the registry and push it — the standard pattern is the same CLI your team already uses, just pointed at your new Harness registry URL.

Push it
$ docker tag payments-service:1.0.0 <registry-url>/payments-service:1.0.0
$ docker push <registry-url>/payments-service:1.0.0
Mission 04 · Make the Delivery0 / 150 XP

Pull your artifact

A registry only matters if something downstream can retrieve what you shipped. Pull the artifact back down — from a laptop, a pipeline step, or a deploy target — using the same authenticated client.

Pull it
$ docker pull <registry-url>/payments-service:1.0.0
Mission 05 · Open Trade Routes0 / 200 XP

Configure an upstream proxy

An upstream proxy lets your registry automatically fetch and cache artifacts from an external source — Docker Hub, Maven Central, or a custom remote — the first time they're requested, then serve every request after from your own dock.

Flip each crate to see the payoff
Mission 06 · Customs Checkpoint0 / 250 XP

Run the Dependency Firewall

Every package fetched through an upstream proxy is screened before it's cached — against CVSS thresholds, license policy, package age, OSS risk, and a malicious-package list refreshed every 4 hours. Each package clears customs as Passed, Warning, or Blocked.

Mission 07 · Clear the Warehouse0 / 200 XP

Write a lifecycle rule

Cleanup rules soft-delete artifacts matching your criteria, recoverable during a grace period. Retention rules are evaluated first and protect matching artifacts from any deletion. Combine criteria — every condition you pick must hold true (AND logic) for a cleanup to fire.
